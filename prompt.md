Final Project (Revised)
🌎 Overview

Build a compelling, publishable-quality native iOS app. This is your chance to put everything you’ve learned into practice — conceiving an original concept, using an AI agent to generate the core of your app, and refining it through deliberate manual editing. You’ll submit your completed Xcode project along with four Markdown files that document your process.
🤔 Rationale

This project mirrors real-world workflows where developers use AI tools to accelerate development while maintaining creative direction and craft. By building something you’re genuinely proud of — something portfolio-worthy — you practice the full arc of native app development: from concept to AI-assisted generation to thoughtful human refinement. The four Markdown deliverables ask you to document and reflect on that process honestly.
🏗️ Structure

Accept the assignment via GitHub Classroom, then clone the starter repo using GitHub Desktop. Your submission is the completed repository, which must contain:

    Your Xcode project folder (the complete app)
    prompt.md — the initial prompt you used to generate your app. You may iterate on your prompt as many times as you like — only include the prompt from the run you’re most happy with.
    edits.md — a numbered list of the adjustments you made to your app after the initial prompt
    reflection.md — a 150–300 word reflection using the three headings: Overall Learnings, Challenges, and Next Steps
    README.md — a polished project README visible to anyone who visits your GitHub repo. It should include your app name and a short description, at least 2–3 screenshots of the running app, and brief setup instructions. Store screenshots in an assets/ folder at the root of your repo and reference them using relative Markdown paths (e.g., ![Home screen](assets/screenshot1.png)). A starter template is provided in the repo.
