# PinPoint

PinPoint is a native iOS app designed to make saving and finding places fast. The core idea is a one-tap `Quick Save` flow for moments like parking your car, while still offering a more flexible `Places` tab for saving multiple named locations. The app combines location services, mapping, and an AirTag-inspired guidance experience to help users get back to a saved spot with as little friction as possible.

## Overview

PinPoint was built around a simple question: how can saving a location feel immediate instead of buried in menus? The app focuses on a fast, low-stress experience where users can open the app, save their current place, and return later to navigate back to it. At the same time, it expands beyond just parking by allowing users to save additional custom places with names and icons.

Key features include:

- One-tap `Quick Save` for fast location capture
- A `Places` tab for saving and managing multiple locations
- AirTag-like guidance back to a saved spot
- Home Screen widgets for quick access to saving and guiding

## Setup

1. Clone this repository and open the Xcode project in the `final-project/` folder.
2. Build and run the app on an iPhone or simulator using Xcode.
3. Allow location access when prompted so PinPoint can save and guide to locations.
4. If testing widgets, run the app once first and then add the widgets from the Home Screen widget gallery.

## Project Structure

- `final-project/` contains the Xcode project and app source code
- `prompt.md` documents the AI prompt used to generate the initial version of the app
- `edits.md` lists the manual changes made after generation
- `reflection.md` contains a short reflection on the process
